# quant-delta-predictor — result collection

Single-purpose repo. It hosts one page: a form for reporting real
quantization accuracy results back to the quant-delta-predictor tool.

Live page: https://gracejackson-sudo.github.io/quant-delta-predictor/

The page is generated by `src/gen_form_page.py` in the main project from the
CLI's own field spec, so the fields cannot drift from what
`rank.py --form-fields` prints. Edit it there, not here.

Submissions go to a Formspree endpoint and are reviewed by a human before
anything enters the dataset. Nothing is ingested automatically, and there is
no tracking on the page.
